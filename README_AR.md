# وينه؟ — مشروع Flutter أولي

تطبيق عربي تجريبي للبحث عن المحلات في النجف، بواجهة RTL وألوان أخضر وأبيض.

## الموجود في هذه النسخة
- شاشة رئيسية عربية.
- البحث في أسماء المحلات ومناطقها وتصنيفاتها.
- بطاقات محلات تجريبية.
- مدخل أولي لإضافة المحلات.

## مهم
المحلات المعروضة تجريبية وليست محلات حقيقية. هذه النسخة لا تحتوي بعد على تسجيل حسابات فعلي أو قاعدة بيانات أو أسعار حقيقية أو طلبات أو دفع إلكتروني أو خرائط مرتبطة بمواقع محلات موثقة.

## بناء ملف APK عبر GitHub
1. أنشئ مستودعاً جديداً باسم `wenha` على GitHub.
2. ارفع **محتويات** هذا المجلد إلى المستودع.
3. افتح تبويب Actions واسمح بتشغيل GitHub Actions إذا طُلب منك.
4. اختر `Build Android APK` ثم `Run workflow`، أو انتظر تشغيله بعد رفع الملفات إلى فرع `main`.
5. بعد نجاح التشغيل، افتح صفحة التشغيل وانزل إلى Artifacts.
6. نزّل `wenha-debug-apk`، وافتح ملف APK على هاتف Android للتثبيت.

## الخصوصية
لا تضع كلمات مرور أو مفاتيح سرية أو بيانات زبائن حقيقية داخل ملفات المشروع.
